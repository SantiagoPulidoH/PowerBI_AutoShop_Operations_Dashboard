# 🚗 Power BI Dashboard — Demo 2 (Taller Mecánico) | Diagnóstico, Utilización e Inventario (2025)

Este repositorio contiene un proyecto de Power BI orientado a un **taller mecánico pequeño**, con enfoque ejecutivo:  
**diagnóstico**, **tiempo perdido (HOLD)**, **utilización de técnicos** e **inventario / proveedores**.  
Incluye un **dashboard completo**, documentación y un informe ejecutivo final.

> 📌 Dataset sintético (no datos reales). El objetivo es demostrar análisis, modelado y storytelling.

---

## 🎯 Objetivo del caso
El taller presenta síntomas típicos de operación “reactiva”:
- Diagnósticos que se quedan esperando (agenda, slots, aprobaciones).
- Mucha capacidad disponible vs horas facturadas (monetización rota).
- Tiempo muerto por motivos HOLD.
- Inventario desbalanceado: capital inmovilizado y riesgo de quiebre (reorder).

Este demo muestra cómo convertir datos operativos en:
✅ hallazgos claros  
✅ impactos económicos aproximados  
✅ plan táctico 90 días
